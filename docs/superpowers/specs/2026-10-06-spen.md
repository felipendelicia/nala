# S Pen fluency and side button

User intent: Nala should feel immediate on the Samsung Tab S10, with Notewise as the subjective target. A configurable S Pen side button must work near/on the sheet. Prior authorization: implement autonomously and publish public builds. Keep the approved logo, black/white theme and defer synchronization.

Design: incremental live ink in page-clipped raster tiles, retaining original vector geometry for saved notes/PDF. Cache only the active stroke, at current display resolution; release images on cancel/up/dispose. Opaque mask before applying stroke opacity prevents repeated darkening of highlighter overlaps. Compare rendered pixels and measure before claiming any improvement. No speculative points in stored ink. Default position smoothing zero and immediate pressure; smoothing remains configurable. Cache immutable stroke bounds to reject irrelevant eraser candidates; skip strokes already erased.

Button: default hold-to-erase; selectable pen, highlighter, eraser, selection or disabled, with hold or toggle behavior. A transition during contact commits the preceding segment before changing tool, so existing ink is retained. Release restores previous tool in hold mode; pointer-up alone does not imply button release. Ignore mouse/touch buttons. Reading, modal routes, cancellation, leaving editor and app focus loss reset temporary state. Native Android channel emits button edges only, including ACTION_BUTTON_PRESS/RELEASE which the pinned Flutter engine ignores. No coordinate stream over MethodChannel. Existing FlutterView already requests unbuffered dispatch; do not duplicate it. No Bluetooth Air Actions promise.

Settings: persist sensitivity, stabilization, button tool and behavior atomically in app root, validate malformed/out of range values, recover to defaults. Make writes visible on failure. Share one app-owned settings controller with editor.

Acceptance: real widget contact/hover/button tests including midstroke, release, read mode, modal and lifecycle; disk restart persistence; long stroke/marker pixel tests; meaningful bounded raster-work diagnostic and native Linux flow. Existing suite/analyze green. Android APK builds and retains same application ID/signature. Hardware latency and Samsung delivery need actual tablet; desktop timing is not end-to-end latency.
