# S Pen implementation

> Execution: inline with superpowers:executing-plans, authorized autonomous work.

**Goal:** Immediate pressure-sensitive handwriting and configurable S Pen side button.
**Spec:** docs/superpowers/specs/2026-10-06-spen.md
**Architecture:** page-clipped incremental live raster mask + retained vector; shared disk settings; input routing tool transitions and native button edges.
**Stack:** Flutter/Dart, Kotlin Android.

## Global Constraints
Keep app ID, original notes/PDFs, logo, black/white theme, page navigation and palm rejection. Synchronization is deferred. Flutter commands serial via tool/flutter-safe. Avoid whole-page raster allocation and MethodChannel point streaming. Keep tests meaningful, geometry intact, release resources. Do not claim physical Notewise-equivalent latency.

## Review Focus
- Marker overlaps/tile seams/zoom resolution; cache memory bounded by sheet, disposal and long off-sheet segments.
- Button edge delivery order vs Flutter input, contact split/up/cancel, hover across modal routes and read mode, Android fallback and non-stylus devices.
- Settings async persistence/recovery and lifecycle restoration without deleting committed ink.
- Eraser bounds rejection for pressure-variable strokes and translated strokes.
- Export retains exact vectors; native Android compilation and existing release signature.
