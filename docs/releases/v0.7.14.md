# Nala 0.7.14

Versión de prueba para Android ARM64 y Linux x64.

- **Colores rápidos.** Elegí hasta tres en **Más herramientas → Personalizar barra → Colores rápidos**. Cambiá de color con un toque desde la barra.
- **Barra flotante.** Mantené presionada el asa con el S Pen o el mouse y arrastrá sin levantarlo. Tocá la chincheta para volver a acoplar la barra.

Para actualizar, abrí **Ajustes → Buscar actualizaciones**. En Android, confirmá en el instalador del sistema. En Linux, cerrá Nala y volvé a abrirla desde el acceso habitual para aplicar el cambio.
