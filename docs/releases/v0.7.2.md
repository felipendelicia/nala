# Nala 0.7.2

La biblioteca reutiliza los cuadernos que ya tiene cargados y vuelve a leer el contenido de las revisiones nuevas. El visor de PDF prepara la página siguiente a la resolución que usa el editor y puede mostrar una vista previa mientras carga una versión más nítida. La sincronización prepara las revisiones para enviarlas en segundo plano.

El conector MCP conserva en memoria el texto extraído de hasta 96 páginas PDF recientes, con un máximo de 12 MiB de texto.

## Mediciones

| Operación de prueba | 0.7.1 | 0.7.2 |
| --- | ---: | ---: |
| Volver a consultar una biblioteca de 14 cuadernos sin cambios | 409 ms | 1,6 ms |
| Volver a consultar la misma biblioteca con un cuaderno actualizado | 315 ms | 17 ms |
| Lecturas de raster al abrir un PDF de dos páginas y avanzar | 3 | 2 |
| Repetir una búsqueda MCP en un PDF de 64 páginas | 1,47 s | 16 ms |

Las mediciones de tiempo son medianas locales en Linux con cuadernos sintéticos. La prueba de PDF usa PDFium con densidad de pantalla simulada de 2×. El catálogo de prueba contiene 196 páginas y 112.896 puntos de tinta.
