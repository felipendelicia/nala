# Nala 0.7.13

Versión de prueba para Android ARM64 y Linux x64.

Activá **Pantalla completa** desde **Ajustes** o desde **Opciones del cuaderno**. En Android, el modo oculta las barras del sistema. En Linux, también podés entrar y salir con **F11**. Al salir, la ventana recupera su estado anterior.

Para actualizar, abrí **Ajustes → Buscar actualizaciones**. En Android, confirmá en el instalador del sistema. En Linux, cerrá Nala y volvé a abrirla desde el acceso habitual para aplicar el cambio.
