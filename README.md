# Nala

Cuadernos y anotaciones sobre PDF para Samsung Tab S10 y Linux.

Proyecto en desarrollo. El editor inicial ya dibuja con lápiz o mouse y permite cambiar entre hojas blancas, rayadas, cuadriculadas y punteadas. Las próximas etapas añaden biblioteca, guardado, PDF y Drive.

Herramientas usadas: Flutter 3.47.6, Dart 3.13.5.

Desde esta carpeta:

```sh
../flutterw pub get
../flutterw test --no-pub
../flutterw run -d linux --no-pub
```

El icono está basado en la perrita de Felipe; ver [branding](docs/branding.md).
